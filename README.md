# record-robotics-demo-website

Demo website for recordrobotics.org written with astro

### Setup

1. Install packages
```bash
$ pnpm install
```

2. Start dev server
```bash
$ pnpm run dev
```

### Development Guide

Astro framework docs: [https://docs.astro.build/en/getting-started/](https://docs.astro.build/en/getting-started/)

Code formatting:
```bash
$ pnpm run format
```
